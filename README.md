# Модель распространения эпидемии Гринберга–Гастингса

Клеточно-автоматная модель эпидемии на двумерной решётке.
Каждая клетка — это «человек», который может находиться в одном из трёх
 состояний: **S** (восприимчивый), **I** (больной),
**R** (невосприимчивый— переболел и приобрёл временный иммунитет).

Модель реализует классическую схему **Гринберга–Гастингса** для
эпидемических процессов и позволяет исследовать распространение заражения,
формирование волн, спиралей и глайдеров, а также влияние порога заражения
и временного иммунитета.

Проект выполнен в рамках курса «Компьютерное моделирование».

---

## 1. Модель

### 1.1. Состояния клетки

Состояние клетки — целое число `s ∈ {0, 1, 2, …, q−1}`:

| Значение `s` | Смысл |
|---|---|
| `0` | **S** — восприимчивый |
| `1 … ⌊q/2⌋` | **I₁ … I_max_inf** — стадии болезни (инкубация, острая фаза и т.п.) |
| `⌊q/2⌋+1 … q−1` | **R** — иммунный (переболел) |

Число стадий болезни `max_inf = ⌊q/2⌋` задаётся параметром `q`.
Чем больше `q`, тем больше стадий болезни и тем дольше клетка остаётся
заразной, прежде чем уйти в класс имунных.

### 1.2. Пространство и соседство

- **Пространство:** двумерная регулярная решётка `m × n`.
- **Окрестность:** Мура (8 соседей).
- **Граничные условия:** периодические (тор, wrap). Поведение на границе
  задаётся параметром `boundary` в функции `update_grid`; возможно изменение на фиксированные границы ( «отсутствующие» соседи
  считаются здоровыми : `mode='constant', cval=0`).

### 1.3. Правила перехода (синхронный шаг)

1. **Заражение.** Восприимчивая клетка `S` переходит в `I₁`, если в её
   окрестности Мура число заражённых (`1 ≤ s ≤ max_inf`) не меньше `k`.
2. **Прогрессия болезни.** Клетка `I_i` с `1 ≤ i < max_inf` переходит в `I_{i+1}`.
3. **Выздоровление.** Клетка на последней стадии `I_max_inf` переходит в `R`
   (значение `max_inf + 1`).
4. **Иммунитет:**
   - **Постоянный** (`immunity_duration = 0`): клетка `R` движется по
     «стадиям R», оставаясь невосприимчивой навсегда.
   - **Временный** (`immunity_duration > 0`): у каждой R-клетки имеется задержка `τ = immunity_duration`; когда таймер истекает, клетка снова
     становится `S`. Это позволяет моделировать утрату иммунитета и
     **повторные волны**.

Все переходы происходят **синхронно**. 

В рамках исследования рассматривалась модель наличия лишь временного иммунитета после заражения. В действительности данная система может описывать появление сезонных заболеваний из-за возникновения новых штаммов одного и того же вируса с 0% летальности.

### 1.4. Параметры модели

| Параметр | Смысл | По умолчанию |
|---|---|---|
| `m`, `n` | Размеры решётки 
| `q` | Число состояний (q > 2) 
| `k` | Порог заражения (k ≥ 1) 
| `immunity_duration` | Длительность иммунитета в шагах; `0` = постоянный 
| `num_patients_zero` | Начальное число заражённых 
| `max_steps` | Число шагов симуляции | 150 |
| `seed` | Зерно генератора случайных чисел | 21 |

**Начальное состояние** задаётся случайно: `num_patients_zero` клеток
равномерно распределяются по полю, каждой присваивается случайная стадия
болезни из диапазона `1 … ⌊q/2⌋`.

## 2. Анализируемые данные

### 2.1. Показатели i-шага

- Число восприимчивых `S`, заражённых `I`, иммунных `R` (по всей решётке).
- Доли `S`, `I`, `R` от общего числа клеток.
- Пиковая доля заражённых `max_I_frac` 
- Время до исчезновения эпидемии `extinction_time` — последний шаг с `I > 0`.

### 2.2. Возможные исследования

- **Распространение заражения / возбуждения** — как фронт инфекции
  движется по решётке.
- **Роль временного иммунитета** — как `immunity_duration` влияет на
  затухание или устойчивость эпидемии.
- **Появление эпидемических волн** — при определённых параметрах фронт
  может повторяться.
- **Влияние порога заражения** `k` — насколько легко/трудно инфекции
  распространяться.
- **Формирование кольцевых и спиральных структур** — устойчивые
  пространственные конфигурации.
- **Условия затухания и устойчивого существования эпидемии**.
- **Глайдеры** — устойчивые локальные структуры, способные бесконечно
  перемещаться по полю `m × n` без затухания и без изменения формы.

## 3. Наблюдения по результатам экспериментов

В ходе численных экспериментов были получены следующие качественные эффекты:

- При **малом числе заражённых** эпидемия может быстро исчезнуть —
  начальный очаг не набирает порог `k` и угасает.
- При **подходящих параметрах** возникают **устойчивые спиральные
  структуры**: в двумерном пространстве наблюдаются вращающиеся спирали,
  визуально похожие на оптические иллюзии. В отличие от классических
  плоских волн «одна волна → период → вторая волна», в проведённых
  экспериментах явных периодических волн получить **не удалось** —
  вместо этого формируется одна **постоянно вращающаяся спираль**. При этом установленно,что увеличение параметра q делает видимые структуры более гладкими.
- Удалось получить **глайдеры**: устойчивые движущиеся структуры разной
  формы и направления движения, которые бесконечно перемещаются по
  решётке `m × n` без затухания.
- **Длительный иммунитет** способен отделять один фронт заражения от
  следующего.
- **Слишком быстрое распространение** иногда приводит к «выгоранию»
  эпидемии: все восприимчивые клетки заражаются, после чего заражать
  становится некого.

## 6. Входные и выходные данные

### Входные

Все начальные условия задаются параметрами и `seed`.

Модель:

- `grid` — целочисленная матрица `m × n` со значениями `0 … q−1`:
  - `0` — S (восприимчивый);
  - `1 … ⌊q/2⌋` — I (стадии болезни);
  - `⌊q/2⌋+1 … q−1` — R (иммунный/удалённый).
- `immunity_timer` — матрица таймеров иммунитета (используется только
  при `immunity_duration > 0`).

### Выходные

- `results/epidemic_runs.csv` — статистика по прогонам;
- `results/epidemic_last_run.gif` — GIF-анимация последнего прогона;
- `results/dynamics_SIR.png` — график S/I/R;
- консольный вывод CLI и скриптов.

---

**Проверка баланса:** `final_S_frac + final_I_frac + final_R_frac = 1` 

### Влияние параметров

- **`k` ↑** → порог заражения выше → эпидемия распространяется медленнее
  или затухает. При больших `k` очаг может погаснуть.
- **`k` ↓** (например, `k = 1`) → инфекция распространяется очень быстро,
  возможен эффект «выгорания»: почти все клетки переболевают,
  `final_R_frac` близка к 1.
- **`immunity_duration` ↑** → дольше сохраняется иммунитет → медленнее
  возвращаются восприимчивые → возможны **повторные волны**.
- **`immunity_duration = 0`** (постоянный иммунитет) → после прохождения
  фронта клетки навсегда выпадают из игры, повторные волны невозможны.
- **`q` ↑** → больше стадий болезни → клетка дольше остаётся заразной,
  фронт движется медленнее, но устойчивее.
- **`num_patients_zero`** мало → при неудачной конфигурации очаг может
  не набрать порог `k`, и эпидемия погаснет.

## 8. Тестирование

Покрыто **9 тестами** в `tests/test_model.py`.

**Функция `initialize_space`:**

1. Форма и тип решётки после инициализации.
2. Число заражённых соответствует запрошенному.
3. Число заражённых не превышает общее число клеток.
4. Стадии болезни укладываются в диапазон `1 … ⌊q/2⌋`.

**Функция `update_grid`:**

5. Заражение срабатывает при `k = 1` и 8 соседях.
6. Заражение **не** срабатывает при `k = 5` и одном заражённом соседе.
7. Переход в `R` при достижении последней стадии `I_max_inf`.
8. Временный иммунитет (`immunity_duration = 1`) возвращает клетку в `S`
   через 1 шаг.
9. Постоянный иммунитет (`immunity_duration = 0`) не возвращает клетку в `S`.

Запуск:

```bash
py -m pytest -q
```

## 9. Верификация и валидация

### Верификация

- принимает на вход матрицу `m × n` и параметры
  `q, k, immunity_duration, boundary`;
- возвращает матрицу `grid` в допустимом диапазоне `0 … q−1`;
- число состояний `S`, `I`, `R` на каждом шаге в сумме даёт `m × n`;
- граничные условия корректно обрабатываются (wrap через `mode='wrap'`,
  фиксированные — через `mode='constant', cval=0`).

### Валидация

- **График S/I/R** качественно совпадает с классической SIR-моделью:
  - `S` монотонно убывает;
  - `I` имеет пик и затем спадает;
  - `R` монотонно растёт.
- **Пространственные структуры** воспроизводят известные для
  клеточно-автоматных моделей эпидемий (Гринберг–Гастингс) эффекты.
- **Поведение при крайних `k`** согласуется с логикой:
  - при `k = 1` инфекция захватывает почти всё поле;
  - при больших `k` очаг быстро гаснет.

Проверки в `scripts/plot_dynamics.py` выполняются автоматически
через `assert`.
